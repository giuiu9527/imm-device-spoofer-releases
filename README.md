# 设备伪装 · 安装包

LSPosed / Xposed 设备指纹伪装模块的安装包发布仓库（源码不在这里）。

| 版本 | 包名 | 下载 |
|---|---|---|
| 全局版 | `com.xianyu.pilot.devicespoofer.scope` | [Releases 里 `scope-v*`](../../releases) |
| 多应用版 | `com.xianyu.pilot.devicespoofer` | [Releases 里 `multi-v*`](../../releases) |

**更新**：装好后在模块首页点「检查更新」即可一键升级（国内会自动走加速镜像，并校验 SHA-256）。

- `scope/update.json`、`multi/update.json` 是应用内更新读取的清单，请勿手动修改。
- 仅供自有设备上的隐私保护与测试使用。
